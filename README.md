# Lekto

Android builds of Lekto: it writes down and translates a class as it is spoken, and practises
spoken conversation with you, through Google's Gemini models straight from the phone.

**Download:** the latest APK is under [Releases](../../releases/latest). Install it on the phone
(Android may ask to allow installing from this source); a newer one installs over it.

The app needs your own Gemini API key, from Google AI Studio, entered in its Settings. It is kept
only on the phone, and everything the app saves stays there.

# لکتو

نسخه‌های اندروید لکتو: کلاس را هم‌زمان می‌نویسد و ترجمه می‌کند، و با تو مکالمه تمرین می‌کند.

**دانلود:** آخرین APK در [Releases](../../releases/latest) است. روی گوشی نصبش کنید؛ نسخه‌ی تازه روی
همین نصب می‌شود.

اپ کلید Gemini API خود شما را می‌خواهد که از Google AI Studio گرفته و در تنظیمات اپ وارد می‌شود و
فقط روی گوشی می‌ماند.
